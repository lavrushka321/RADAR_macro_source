# RADAR Macro

Внешний Windows-инструмент для Roblox. Захватывает **только клиентскую область
окна игры**, ищет движение и цели и показывает радар, тепловизор или рамки в
`RADAR_VIEW` либо поверх игры. В процесс Roblox не внедряется и файлы игры не
меняет.

## Запуск

Требования: Windows 10/11, Python 3.11+, запущенный Roblox в оконном или
безрамочном режиме.

Используя exe файл:

1.Скачать из релиза и распаковать из архива

2.По желанию: создать ярлык и поменять иконку

Используя python файл:

```bash
pip install -r requirements.txt
python main.py
```

Для настройки биндов и параметров:

```bash
python bind_settings.py
```

`main.py` читает настройки при старте. После сохранения конфига перезапустите
макрос. Перед редактированием закройте его, иначе старые бинды продолжат
срабатывать.

Кадры захватываются через `PrintWindow`, клавиши читаются через
`GetAsyncKeyState`; `pydirectinput` используется для удержания клавиш коррекции.

## Управление

Клавиши по умолчанию; все они меняются в `BINDS`, клавиши коррекции — в
`CENTER_KEY_*`.

| Клавиша | Действие |
| --- | --- |
| `ESC` | Полное завершение |
| `F` (удерживать) | Радар: поиск движения в квадрате вокруг курсора |
| `Q` | Тепловизор всего клиента Roblox (повторно — выключить) |
| `Y` | Тепловизор: окно `RADAR_VIEW` или оверлей на весь экран |
| `H` | Полный поиск целей по всему окну (повторно — выключить) |
| `V` | Слежение за целью: `LOCK` → цель радара `F` → главная цель `H` |
| `G` | Переключить профиль поиска (`precision` / `noise`) |
| `Z` | Увеличить `RADAR_VIEW` и картинку в 2 раза |
| `RMB` (удерживать) | Цифровой TV-прицел ×2 вокруг курсора или цели |
| `T` | Захватить/сменить цель рядом с курсором; на текущей — снять `LOCK` |
| `X` | Размер хардлока: `NORMAL` → `FAR` → `NEAR` |
| `N` | Удерживать цель в центре клавишами `A/D/W/S` |
| `Ё` | Свернуть/развернуть оверлей |
| Кнопка `UI: NEW/NORMAL` | Переключить интерфейс и сохранить `INTERFACE_MODE` |

## Что умеет

- **Радар `F`** сканирует область `SQUARE_SIZE` вокруг курсора. Курсор должен
  быть над окном Roblox. В `RADAR_VIEW` показывается сырая карта движения
  (`absdiff`) до фильтров, усиленная в `MOTION_MAP_GAIN` раз.
- **Тепловизор `Q`** строит чёрно-белую (`white-hot`) карту движения всего
  клиента. В режиме `window` кадр вписывается в `RADAR_VIEW`, в режиме
  `overlay` рисуется поверх игры. Режим переключает `Y` и сохраняет в
  `THERMAL_MODE`.
- **Полный поиск `H`** ищет цели по всему окну с активным профилем
  `SEARCH_PROFILES`. Работает независимо от `Q`; можно включить только `Q`,
  только `H` или оба режима. При `Q+H` кадр захватывается один раз.
- **TV-прицел `RMB`** — только цифровое увеличение отображения: камера Roblox
  не двигается. Без `Q` показывает игру, с `Q` — увеличенный тепловизор.
- **`Z`** меняет только масштаб `RADAR_VIEW`; поиск и координаты целей не
  меняются.

## Настройка

`bind_settings.py` — отдельное окно с вкладками:

- `Бинды` — действия из `BINDS`; нажмите кнопку и затем нужную клавишу или
  кнопку мыши (`LMB`, `RMB`, `MMB`, `XBUTTON1`, `XBUTTON2`).
- `Корректировка` — `CENTER_USE_KEYS`, `CENTER_KEY_LEFT/RIGHT/UP/DOWN` (по
  умолчанию `A/D/W/S`), `CENTER_HOLD_SECONDS`, `CENTER_REST_SECONDS`,
  `CENTER_AUTO_RMB`.
- `Основные` — `SQUARE_SIZE`, `SCAN_INTERVAL`, `SHOW_RADAR_VIEW`,
  `MOTION_MAP_GAIN`, `INTERFACE_MODE`, `LOCK_SIZE_MODE`, `THERMAL_MODE`,
  `ACTIVE_PROFILE`.
- `Поиск` — профили `SEARCH_PROFILES`.
- `LOCK` — все параметры `LOCK_SETTINGS`.
- `Тепловизор` — `THERMAL_SETTINGS` и список окон `THERMAL_WINDOWS`.

Проверяются повторяющиеся клавиши среди `BINDS` и `CENTER_KEY_*`, несовместимые
размеры `LOCK` и условие `max_area > min_area` у профилей. «Сбросить бинды»
возвращает только бинды и клавиши коррекции. Неизвестные ключи конфига, профили
и записи `BINDS` сохраняются без изменений.

## Конфиг

Путь: `%USERPROFILE%\.radar_macro\config.json` (в Python —
`~/.radar_macro/config.json`). Файл создаётся автоматически, дополняется
дефолтами, а битый сохраняется рядом как `config.json.bad`.

| Ключ | Назначение |
| --- | --- |
| `BINDS` | Клавиши и кнопки мыши для действий |
| `CENTER_*` | Коррекция цели в центре: клавиши, тайминги, режим |
| `SEARCH_PROFILES`, `ACTIVE_PROFILE` | Профили поиска и активный профиль |
| `LOCK_SETTINGS`, `LOCK_SIZE_MODE` | Параметры и размер хардлока |
| `THERMAL_SETTINGS`, `THERMAL_MODE`, `THERMAL_WINDOWS` | Тепловизор |
| `SQUARE_SIZE`, `SCAN_INTERVAL`, `SHOW_RADAR_VIEW` | Общие параметры сканирования |
| `MOTION_MAP_GAIN` | Усиление карты движения в `RADAR_VIEW` |
| `INTERFACE_MODE` | `new` (TV-интерфейс) или `normal` |
| `CONFIG_VERSION` | Версия схемы; обновляется автоматически |

`H` всегда открывает `RADAR_VIEW`, даже при `SHOW_RADAR_VIEW: false`. `Q`
открывает его только в режиме `window`; в `overlay` мини-окно не требуется.
Когда активным режимам больше не нужно окно, оно закрывается.

## Поиск и профили

Профили: `precision` (по умолчанию, максимальная чувствительность) и `noise`
(защита от помех на подвижном фоне). `G` переключает профиль для `F` и `H`.

| Параметр | Влияние |
| --- | --- |
| `threshold` | Порог движения |
| `dilate`, `blur`, `open` | Морфология и сглаживание |
| `min_seed`, `min_area`, `max_area` | Размер и площадь блобов |
| `min_fill`, `max_aspect` | Плотность и вытянутость цели |
| `max_motion_ratio` | Пропуск кадра при резкой смене картинки |
| `adaptive` | Автоподъём порога при движении фона |
| `min_hits`, `max_misses`, `match_dist` | Подтверждение цели на нескольких сканах |

## LOCK и коррекция

`T` ищет цель рядом с курсором: сначала готовые рамки `F`/`H`, затем локальный
поиск по контрасту. Захват работает и без `F`, в том числе при `TARGETS: 0`.
Сопоставление идёт по шаблону и его центральным кропам, поэтому фон по краям не
срывает `LOCK`. Банк эталонов хранит цель на разных фонах и ракурсах.

- `X` переключает `NORMAL`/`FAR`/`NEAR`; при активном `LOCK` шаблон
  переснимается сразу.
- Если `F` отпущена, `LOCK` не снимается: рамка продолжает обновляться в фоне.
  При активном поиске `T` включает `V`; без поиска `V` автоматически не
  включается.
- После промахов поиск расширяется (`wide_margin`), затем включается
  `lost_timeout` с радиусом `lost_margin`. Если цель не найдена — `LOCK`
  снимается.
- `V` только включает/выключает ведение курсора и сам `LOCK` не снимает.
- `N` зажимает клавиши коррекции, пока цель не в центре, но не дольше
  `CENTER_HOLD_SECONDS`; между сериями пауза `CENTER_REST_SECONDS`. Курсор не
  двигается. Клавиши отпускаются, если Roblox неактивен или курсор над
  `RADAR_VIEW`.

Основные поля `LOCK_SETTINGS`: `template_size`, `far_size`, `near_size`,
`search_margin`, `wide_margin`, `match_min`, `wide_match_min`, `max_misses`,
`lost_margin`, `lost_timeout`, `lost_match_min`, `update_score`,
`template_bank_size`, `bank_add_score`, `bank_diff_min`.

## Тепловизор: Num-клавиши

Включите NumLock.

| Клавиши | Действие |
| --- | --- |
| `Num +` / `Num -` | Чувствительность (`threshold`) |
| `Num 8` / `Num 2` | Размер точки |
| `Num 6` / `Num 4` | Шаг выборки: меньше точек — выше FPS |
| `Num 9` / `Num 7` | Яркость фона или затемнение `overlay` |

Изменения сохраняются при выключении тепловизора.

## Файлы

- `main.py` — основной макрос: захват, поиск, `RADAR_VIEW`, `LOCK`, тепловизор.
- `bind_settings.py` — отдельное окно настройки биндов и параметров.
- `requirements.txt` — зависимости Python.
- `shangelog.txt` — история изменений.

## Важно

- Захватывается только клиентская область Roblox; рабочий стол, другие окна и
  собственный оверлей в кадр не попадают.
- Для `key_zoom_hold` и других биндов поддерживаются мышиные имена `LMB`,
  `RMB`, `MMB`, `XBUTTON1`, `XBUTTON2`.
- Конфиг читается при старте. После `Сохранить` в `bind_settings.py` закройте
  и снова запустите `main.py`.
- Неизвестные ключи и дополнительные профили не удаляются.
- Версия: **beta-3.7**.
